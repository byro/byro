# Contributing to byro

Thank you for your interest in improving byro! Whether you have found a bug,
would like to improve the documentation, or have an idea for the project, your
contribution is welcome.

If you already know what you would like to change, please [open an issue](https://github.com/byro/byro/issues/new) first. This gives us a chance
to discuss the idea, avoid duplicated work, and help you get started. You can
also look through the [open issues](https://github.com/byro/byro/issues) for
ideas to work on.

Ready to contribute? Our [contributor documentation](https://byro.readthedocs.io/en/latest/development/contributing/) has the practical guide: it covers setting up a development environment,
creating a branch and pull request, running the checks, and our contribution
guidelines.

byro is extended through plugins, which are published as independent Python
packages. If you would like to build one, see the [plugin development documentation](https://byro.readthedocs.io/en/latest/development/plugins/overview/).

We appreciate the time and care you put into helping make byro better.

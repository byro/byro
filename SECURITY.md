# Security Policy

## Supported versions

We provide security fixes for the latest published byro release. If you use an
older release, please update before reporting an issue whenever possible.

| Version | Supported |
| --- | --- |
| Latest release | :white_check_mark: |
| Earlier releases | :x: |

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through public issues,
pull requests, or discussions. Instead, use GitHub's [private vulnerability reporting form](https://github.com/byro/byro/security/advisories), available
from the repository's **Security** tab.

Please include a clear description of the issue, its potential impact, affected
versions, and steps to reproduce it. A proof of concept is helpful when it can
be shared safely.

We will acknowledge your report and work with you to understand and resolve the
issue. Please give us reasonable time to prepare a fix before disclosing the
vulnerability publicly.

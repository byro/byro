# Unterstützen

Dieser Teil der byro-Dokumentation ist für dich, wenn du byro verbessern,
Dokumentation bearbeiten oder zu einem Release beitragen willst.

Wenn du byro selbst verbessern willst, lies unsere
[Hinweise zum Mitwirken](contributing.md).

Wenn du am Code von byro arbeiten willst (egal an welchem Teil), fang mit dem
[Entwicklungs-Setup](setup.md) an. Es enthält die Richtlinien fürs Mitwirken,
eine Erklärung, wie ein Pull Request entsteht, welche Stilregeln gelten, und
eine interne API-Dokumentation.

Die [REST-API](api.md) hat einen eigenen Bereich. Anleitungen zur
Plugin-Entwicklung und die [Signalliste](signals.md) stehen im Bereich
[Plugins](../administration/plugins.md) unter
[Plugin-Entwicklung](plugins/overview.md).

Wenn du byro betreust und ein Release vorbereitest, beschreibt
[byro veröffentlichen](releasing.md) die Release-Pipeline, den
`stable`-Zeiger für byroctl und die Release-Flags.

Ist ein Teil der Dokumentation unklar, lies unter
[An der Dokumentation arbeiten](documentation.md), wie du sie verbesserst, und
folge dann den [Hinweisen zum Mitwirken](contributing.md), um einen Pull
Request zu erstellen.

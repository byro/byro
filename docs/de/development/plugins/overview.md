# Plugin-Entwicklung

Ohne Plugins wird byro für dich kaum nutzbar sein. Wir empfehlen einen Blick in
unsere [GitHub-Organisation](https://github.com/byro), um zu sehen, welche
Plugins es schon gibt und wie du sie an deine Anwendungsfälle anpassen kannst.

Die Möglichkeiten von byro-Plugins sollen grenzenlos sein. Stößt du also auf
etwas, das du mit einem Plugin tun willst, und dir fehlt ein Plugin-Hook,
[sag es uns](https://github.com/byro/byro/issues/new), und wir ergänzen gern
einen Hook.

Die folgenden Seiten behandeln die Funktionsweise von Plugins im Allgemeinen,
listen die bisher vorhandenen Plugin-Hooks und zeigen, wie man Mitgliedsdaten
speichert, die byro nicht von Haus aus kennt, oder einen eigenen
Zahlungsimport ergänzt.

- [Ein Plugin erstellen](creating-a-plugin.md)
- [Signalliste](../signals.md)
- [Plugin: Eigene Mitgliedsdaten](member-data.md)
- [Bankimporter](bank-transaction-importers.md)

Kommst du mit dieser Dokumentation nicht weiter,
[sag es uns](https://github.com/byro/byro/issues/new) ebenfalls.
